# شقتنا

التصميم الداخلي للشقة كـ Web app: موديل 3D تقدر تلف فيه وتدخل كل أوضة، والمسقط بالعفش قبل وبعد التعديل، وتفاصيل كل غرفة والخامات.

- الموديل مبني بـ three.js من نفس أبعاد ملف الأوتوكاد.
- تقدر تنزّله على الموبايل: من المتصفح اختار "Add to Home Screen" أو "تثبيت التطبيق"، وبيشتغل من غير نت بعد أول فتحة.
